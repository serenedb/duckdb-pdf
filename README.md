# SereneDB PDF readers

SereneDB's PDF extension provides text readers and document inspection under the
repository's [Apache-2.0 license](LICENSE).
PoDoFo is used under MPL-2.0, and FreeType under the FreeType License.
Their licenses, attribution, and source references accompany binary releases.

The SQL contract is documented in `docs/sql/functions/pdf.md` in the parent
repository. Text extraction supports local files, glob patterns, passwords,
page ranges, geometric reading order, and original content order. Ruled tables
support merged cells and missing outer borders. OCR, unruled tables, and document
editing are unsupported.

| Function | Result | Options |
|---|---|---|
| `read_pdf(path)` | One row per page: filename, page, text, dimensions, text-layer flag | password, first_page, last_page, layout (`auto` or `raw`) |
| `read_pdf_blocks(path)` | One row per text block: filename, page, block, text, position and dimensions | password, first_page, last_page |
| `read_pdf_tables(path)` | One row per ruled-table row: filename, page, table_index, row_index, cells | password, first_page, last_page |
| `read_pdf_meta(path)` | One row per file: filename, title, author, subject, keywords, creator, producer, pages, pdf_version, encrypted | password, ignore_errors |
| `pdf_outline(path)` | One row per bookmark in depth-first order: file, ord, depth, title, page | password, ignore_errors |
| `pdf_attachments(path)` | One row per embedded file: file, name, description, size, mime_type, data (BLOB) | password |

Functions not listed above remain unavailable. The upstream GPL implementation is not included in this tree; its history retains the original license. This replacement does not claim full upstream API compatibility.

Tests for each reader are in `test/sql/`. Their `varusik` fixtures are generated by `tests/sqllogic/fixtures/pdf/generate.py` in SereneDB. From the SereneDB checkout, run `scripts/ci/test.py --build-dir <build> --suite duckdb --duckdb-suite pdf` after building `unittest`.
